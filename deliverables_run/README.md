# Deliverables — Minimal Package

Project: Smart Glasses Distilled — Submission Deliverables
Author: Ahmed Moussa
Date: 2026-06-20

This folder contains the minimal deliverable package prepared for academic evaluation. It is intended to be runnable and verifiable by the examiners while protecting sensitive source code.

Included (short):
- final_documentation.pdf (place your final PDF here)
- slides.pdf (optimized slide PDF)
- docker_image.tar (optional: Docker image saved with `docker save`)
- bin/ (optional compiled binaries)
- src_minimal/ (minimal invocation stubs and API spec)
- run_demo.sh / run_demo.ps1 (runners)
- package.sh / package.ps1 (packaging scripts)
- checksums.sha256, checksums.sha256.sig (generated by packaging)
- full_source_encrypted.tar.gpg (encrypted full repo for NDA release)

How to run (preferred — Docker):

1. Open a terminal in this folder.
2. Load the Docker image:

   docker load -i docker_image.tar

3. Run the container:

   docker run --rm -p 8000:8000 --name smartglasses_demo smartglasses:deliverable

4. Health check:

   curl -sS http://127.0.0.1:8000/health

If Docker is not available, run the binary fallback in `bin/` (if provided):

Windows (PowerShell):
  .\bin\app_demo.exe --demo-mode

Linux/macOS:
  chmod +x bin/app_demo
  ./bin/app_demo --demo-mode

What is withheld (sensitive):
- models/ (trained model files and training scripts)
- app/agent/ (inference & agent orchestration layer)
- clients/Expo/assets/navigation/ (GLB-to-2D pipeline and raw meshes)
- scripts/ (data generation and training pipelines)

Full source is included on this media as an encrypted archive `full_source_encrypted.tar.gpg`. The passphrase is released only after a signed NDA is returned. To request the full source, contact: your-email@example.com

Integrity:
- checksums.sha256 contains SHA256 hashes for all delivered files; verify with `sha256sum -c checksums.sha256` or PowerShell `Get-FileHash`.
- checksums.sha256.sig is a detached GPG signature; verify with `gpg --verify checksums.sha256.sig checksums.sha256`.
