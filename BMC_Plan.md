# Business Model Canvas (BMC)

Project: Smart Glasses (Cerebro)  
Date: 2026-04-24  
Currency: EGP

| Block                  | BMC Content                                                                                                                                                                                                                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Key Partnerships       | New Mansoura University (supervisors, labs, pilot validation), component suppliers (ESP32, camera, microphones, batteries), AI/open-source ecosystem (YOLO, Whisper, Gemma, OpenCV), cloud and payment providers, pilot institutions (universities, hospitals, enterprises), community contributors. |
| Key Activities         | Hardware prototyping and assembly, firmware and backend development, multimodal AI integration (speech, vision, LLM), indoor mapping and routing, accessibility testing, deployment and support, documentation and community operations.                                                             |
| Key Resources          | 10-person technical team, hardware modules and prototypes, AI models and software stack, indoor map and training data assets, cloud infrastructure, institutional network, project brand and research credibility.                                                                                   |
| Value Propositions     | Eyes-free and hands-free context-aware assistant, real-time multilingual speech support, object and scene understanding, indoor navigation aid, accessibility-focused interaction for users with disabilities, smart-home and device-control integration.                                            |
| Customer Relationships | Self-serve onboarding for individuals, managed onboarding/training for institutions, ongoing support contracts, community-led support for open users, continuous user feedback loops for accessibility and reliability improvements.                                                                 |
| Channels               | University demos and exhibitions, social media and video showcases, GitHub/open-source presence, direct device sales, institutional outreach, partner-driven pilots and referrals.                                                                                                                   |
| Customer Segments      | Students and educators, people with visual/hearing accessibility needs, field engineers and technicians, travelers and multilingual users, smart-home users, institutions (universities, hospitals, enterprises, campuses).                                                                          |
| Cost Structure         | Variable cost: hardware COGS at 3,000 EGP per unit. Fixed cost baseline from finance plan: Plan A at 292,000 EGP/month and Plan B at 189,000 EGP/month, including labor, hosting, R&D, facilities, and operating reserve.                                                                            |
| Revenue Streams        | Hardware unit sales, software subscriptions, managed support contracts, sponsor contributions, donations/crowdfunding, grants and innovation awards, optional premium cloud services.                                                                                                                |
